## 📌 Description
Web app enabling users to draw digits on an interactive HTML5 canvas and recognize them using a PyTorch CNN model.

---

## 🛠️ Architecture & Highlights
- **Production Modular Design**: Standard clean code layout with runnable script entry point.
- **Extensible**: Ready for cloud deployment, Docker microservice wrapping, or educational analysis.

---

## 📦 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparkx313/dl-mnist-digit-recognizer-web.git
   cd dl-mnist-digit-recognizer-web
   ```

2. **Run the entry point**:
   ```bash
   python digit_app.py
   ```
